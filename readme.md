# Sistema de Administración de Switches HRAEM

Sistema web para administrar los nodos de red del hospital,
basado en el Excel "Ordenamiento Switches 2024".

## Stack

- Python 3.12
- Django 5
- PostgreSQL 16
- pandas + openpyxl
- Bootstrap 5 + HTMX

## Requisitos previos

- Python 3.12+
- PostgreSQL 16+
- Git

## Instalación

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/tu-usuario/sistema-switches-HRAEM.git
   cd sistema-switches
   ```
